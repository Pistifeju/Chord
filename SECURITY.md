# Security

## Report a vulnerability

Report it in private from the repository's Security tab with "Report a vulnerability". Keep it out of public issues and pull requests until a fix ships.

Include:

- the Chord version or commit, and your macOS version
- the harness and its version, when the bug needs one
- the steps that reproduce it, or a proof of concept
- what an attacker gains

You get a reply in the advisory thread, and credit in the advisory unless you decline it.

## Supported versions

Chord is in early development. Security fixes ship in the latest release.

## Out of scope

- A bug in pi, Codex, Claude Code, OpenCode, git or Xcode. Report it to that project.
- An attack that starts with code already running as your user.
