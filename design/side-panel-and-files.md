# Side panel and Files

- **Side panel:** in a worktree with an Xcode project, one column right of the panes, under the toolbar to the status bar, 300px wide by default, on `canvas` with a 1px `line` left edge. Dragging the left edge resizes it between 200px and 640px, and it leaves the panes 320px at least; the edge has a divider's 9px grab area centered on the border and takes `line-strong` on hover and drag. Open state and width are saved per worktree. It shows one view at a time, saved per worktree: the Simulator or the Preview view. A project that builds for macOS alone has the Preview view alone: no Simulator view, no phone button, and ⌘⇧S does nothing. Files and Changes live in the sidebar's navigator; a panel saved on one of them closes. The toolbar's right end holds one icon button per view: the Simulator view's phone (tooltip "Show or Hide Simulator (⌘⇧S)"), then the Preview view's eye (tooltip "Show or Hide Preview (⌘⇧P)"). They are plain icon buttons 2px apart with no capsule, as Run and Stop at the toolbar's left end. A button takes `selected` while its view shows. A click or the shortcut hides the panel while it shows that view, and otherwise opens the panel on it.
- **Files filter:** the view's first row, 4px 8px padding: a 28px Field with buttons (placeholder "Filter", no icon; see Inputs) holding Collapse All (two chevrons pointing in at each other, disabled while no folder is open) and Reload. The project's name sits in the title bar row (see Layout).
- **Tree:** rows are 26px, Control radius, `ink-secondary` text, 16px more indent per level, a 12px `ink-muted` chevron (turns like a step group's; a file keeps its space and shows none), then a 16px `ink-muted` folder or file icon (`ink-secondary` on the selected row), 4px apart, then the name truncating. Hover takes `raised`, pressed takes `selected`; the selected file takes `selected` and `ink`. A folder chain reads as one row (`src/app/views`). The focus ring sits inside the row. ↑ and ↓ move the focus between rows, → opens a folder, ← closes an open folder or moves to the parent's row, Return opens a file as a click does. A filter with no match reads "No matches" in meta text.
- **Tree drag:** a file row dragged onto a chat's composer dims to 60% like a dragged tab; the composer under it takes a 2px dashed `accent-ink` outline on `accent-wash`. Dropping adds the file's relative path to the end of the draft, a space apart, and focuses the composer. A disabled composer takes no drop.
- **Tree menu:** right-click on a row opens New File and New Folder (inside a folder, beside a file), Rename, Copy Path, Copy Relative Path, Reveal in Finder and Move to Trash (⌘⌫ on the focused row); right-click on the empty tree opens New File and New Folder at the root. Move to Trash asks with a confirm sheet first.
- **Open File by Name:** ⌘⇧O opens a sheet 560px wide with 12px padding: a Field (placeholder "File name") with the focus, then the worktree's files that git does not ignore as 30px rows, 312px tall at most, scrolling inside. A row is a 16px `ink-muted` file icon, the file name in `ink-secondary`, then its folder in `ink-muted` meta text, both truncating; the full path is its tooltip. A path matches when it holds the typed letters in order, ignoring case and spaces: `ofbn` finds `OpenFileByNamePopup.tsx`, `files store` finds `files/store.ts`. A letter scores more in the file name, at the start of a word (after `/`, `.`, `_`, `-` or a camelCase capital) and right after the previous match; the best score comes first, and among equals the file opened last in this worktree. An empty field lists the files opened in this session first, latest first. The first 100 show. The highlighted row takes `selected` and `ink`, moves with ↑ and ↓ or the pointer, and Return or a click opens the file as a click in the tree does. No match reads "No matches" in meta text. Esc or a click outside closes it.
- **Name field:** Rename turns the row's name into a 22px field (`canvas`, 1px `line-strong` border, Control radius) with the name without its extension selected; New File and New Folder show the same field as the first row inside their folder. Return or leaving the field keeps the name, Esc or an empty name drops it. A new file opens in its tab.
