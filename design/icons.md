# Icons

Line icons drawn in `src/ui/icons.tsx` on a 16px grid with a 1.3px stroke, in the current text color.
Add a new icon there in the same stroke.
No text glyph stands in for an icon.

The harness logos (pi, Codex, Claude Code, OpenCode) are the brands' own marks in their brand colors, from the `--brand-*` tokens.
OpenCode ships a light and a dark version of its mark, so its two tokens change with the theme.
